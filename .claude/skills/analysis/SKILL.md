以下のデータまたはテーマについて、統計分析と可視化を行ってください。

# 分析の進め方
1. データの概要把握（件数、期間、欠損値、型）
2. 基本統計量の算出（平均、中央値、標準偏差、分布）
3. 可視化（傾向、比較、分布、相関）
4. 分析結果の解釈（何が読み取れるか）
5. 示唆（ビジネス上どう活かせるか）

# マーケティングデータの場合の追加分析
マーケティング指標（広告、Web、SNS等）が含まれる場合：
- 主要なトレンドと変化（上昇・下降している指標とその度合い）
- 予想外の結果とその考えられる要因
- ユーザー・顧客行動に関する洞察
- すぐに実行すべき施策（3つ）
- 中期的に検討すべき戦略調整（2〜3つ）
- さらに収集・分析すべきデータの提案

# ROI分析の場合の追加分析
投資額と成果指標が含まれる場合：
- 現時点でのROI計算（計算式と根拠を明示）
- 短期ROIと長期ROI（LTVベース）の比較
- ROIを向上させるための具体的な提案（3〜5つ）
- 同様の予算での代替案の予測ROI
- 予算配分の最適化提案
- 非マーケティング部門にも理解しやすい説明を心がける

# ルール
- Python（pandas, matplotlib, seaborn, plotly）でコードを書いて実行する
- グラフは日本語ラベルを使う。文字化けしないようフォント設定を行う
- グラフのタイトル、軸ラベル、凡例は必ずつける
- 外れ値や欠損値の処理方針は、処理前に明記する
- 相関と因果を混同しない。因果を主張する場合は根拠を示す
- 分析結果を報告する際は、数字の羅列ではなく「だから何が言えるか」を添える
- 再現性のため、コードはすべて残す

# 出力形式
- 分析サマリー（要点3つ以内）
- 可視化（グラフ画像）
- 詳細分析（コード付き）
- 示唆とネクストアクション
