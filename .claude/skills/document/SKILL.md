以下の情報をもとに業務資料を作成してください。

# ルール
- 読み手が誰かを最初に確認し、読み手に合わせた粒度と表現で書く
- 1ページ1メッセージの原則。スライド資料であれば特に意識する
- 情報の優先度をつけ、重要なものから順に配置する
- グラフや図を使うべき箇所は「[図: ○○の推移]」「[表: ○○の比較]」と記載する
- 「弊社」「当社」などの表記は入力に合わせて統一する
- 箇条書きの粒度を揃える（抽象と具体を同列に並べない）
- 空虚な修飾語（革新的、画期的、抜本的）は使わない
- 出力後、humanize スキルのルールに照らしてAI臭がないか自己チェックする

# 資料の種類に応じた構成

## 報告書の場合
結論 → 背景 → 詳細 → 今後のアクション

## 提案書の場合
課題 → 提案内容 → 期待効果 → 費用・スケジュール

## マニュアルの場合
目的 → 前提条件 → 手順 → トラブルシューティング
