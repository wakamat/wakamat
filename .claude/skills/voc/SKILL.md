以下の顧客レビュー・フィードバックを分析し、重要なインサイトをまとめてください。

# 分析の観点
1. 肯定的な意見の主要テーマ（最も言及されている良い点）
2. 否定的な意見の主要テーマ（最も言及されている問題点）
3. 頻出キーワードとその文脈
4. 顧客の期待と実際の体験のギャップ
5. 競合製品・サービスとの比較に関するコメント
6. 顧客セグメント別の傾向（言及されている場合）
7. 感情分析のサマリー（ポジティブ、ネガティブ、中立の割合）

# 分析から導く提案
1. 商品・サービス改善のための具体的な提案（3〜5つ）
2. マーケティングメッセージに活かせるポジティブな要素
3. 対応すべき顧客の懸念事項
4. 今後収集すべき追加情報

# ルール
- レビューの原文を尊重し、意図を歪めない
- 少数意見でも重要な指摘は見落とさない
- 定量的な集計（件数、割合）と定性的な分析の両方を行う
- 改善提案は具体的かつ実行可能なものにする
