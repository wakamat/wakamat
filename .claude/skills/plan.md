# 実装計画

新しい機能やリファクタリングの実装計画を、チームで策定してください。

## チーム構成

1. **アーキテクト**: 全体設計、モジュール分割、技術選定を担当
2. **フロントエンド担当**: UI/UX、コンポーネント設計を担当
3. **バックエンド担当**: API設計、データモデル、インフラを担当
4. **デビルズアドボケイト**: 全員の計画にツッコミを入れ、リスクや見落としを指摘する

## 進め方

- 各メンバーはプラン承認モードで動作する（実装前にリーダーの承認が必要）
- デビルズアドボケイトが全員の計画をレビューし、問題点を共有
- リーダーは各プランを承認・却下し、最終的な実装計画をまとめる

## 成果物

- タスク一覧（依存関係つき）
- 各タスクの担当者と見積もり
- リスクと対策
