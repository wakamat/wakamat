以下の企画内容をもとに、動作するモックアップを作成してください。

# 技術スタック
- HTML + Tailwind CSS（CDN）でシングルファイル構成
- インタラクションが必要な場合は vanilla JavaScript を使用
- 複雑なモックの場合は React + Vite を検討

# ルール
- まず画面一覧を洗い出し、ユーザーの確認を取ってから実装に入る
- モバイルファースト。レスポンシブ対応を必ず行う
- ダミーデータはリアルに見える日本語データを使う（山田太郎、株式会社○○ 等）
- 色やフォントの指定がなければ、シンプルで清潔感のあるデザインにする
- ナビゲーション、ボタン、フォームは実際にクリック・遷移できる状態にする
- 画像はプレースホルダー（グレーの矩形＋サイズ表記）で代替する
- 完成したらブラウザで確認できる手順を添える

# 出力
- HTML ファイル（そのまま開いて動作確認できるもの）
- 画面構成の説明（どの画面で何ができるか）
