以下の情報に基づいて、5ステップのメールマーケティングシナリオを作成してください。

# 5ステップの構成
1. 初回メール：関心喚起と関係構築
2. 第2メール：価値提案と教育的コンテンツ
3. 第3メール：具体的なベネフィットと社会的証明
4. 第4メール：オファーの提示と行動喚起
5. 最終メール：決断促進と希少性・緊急性の演出

# 各メールに含める要素
- 件名案（3つずつ）
- メール本文（導入、本文、CTA）
- 送信タイミングの提案
- 想定される開封率・クリック率の目標
- A/Bテストすべき要素の提案

# ルール
- 全体を通して一貫したストーリーラインを作る
- 段階的に信頼を構築する流れにする
- 各メールは独立しても読めるが、シリーズとして読むとより効果的な設計にする
- 件名は開封したくなる具体性を持たせる。煽りすぎない
- CTAは1メールにつき1つに絞る
- AI臭のある表現を使わない（humanize スキルのルールに準拠）
- 配信停止への配慮（フッターの案内）を忘れない
