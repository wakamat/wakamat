以下の情報に基づいて、3ヶ月間のコンテンツマーケティング計画を作成してください。

# 計画に含める要素
1. 3ヶ月間の全体戦略と期待される成果
2. 月別の重点テーマと主要コンテンツ
3. 各チャネルで発信すべきコンテンツタイプと頻度
4. 具体的なコンテンツアイデア（タイトル案を各月5つずつ）
5. KPIと測定方法
6. リソース配分の提案（外注すべき部分など）

# ルール
- 現実的で実行可能な計画にする。リソースと予算を無視した理想論にしない
- 各コンテンツにはターゲットと期待する行動を明記する
- 季節性やイベントカレンダーを考慮する
- コンテンツ間の連携（ブログ→SNS→メルマガの導線）を設計する
- 既存コンテンツの再活用も提案に含める
