# バグ調査

報告されたバグや問題を、複数の仮説で並行調査するエージェントチームを作成してください。

## チーム構成

5人のチームメンバーをスポーンし、それぞれ異なる仮説を担当させてください。

## 進め方

- 各メンバーは自分の仮説を検証する
- 他のメンバーの仮説に反論（反証）を試みる（科学的ディベート方式）
- 反証されなかった仮説が最も有力な原因候補
- リーダーは議論を統合し、根本原因と修正案を報告する

## 報告フォーマット

1. **根本原因**: 最も可能性の高い原因
2. **証拠**: その結論に至った根拠
3. **却下された仮説**: 他の仮説とその反証理由
4. **修正案**: 具体的な修正手順
